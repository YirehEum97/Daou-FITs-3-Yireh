### 코드 예시

아래의 코드를 실행하면 버튼을 클릭했을 때 Hello world!를 콘솔창에 출력하는 창이 생긴다.

```java
package javafxexam;

import javafx.application.Application;
import javafx.event.ActionEvent;
import javafx.event.EventHandler;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.layout.StackPane;
import javafx.stage.Stage;

public class JavafxExample extends Application {

    @Override
    public void start(Stage primaryStage) {
        // 버튼 생성
        Button btn = new Button();
        // 버튼에 text 설정
        btn.setText("Hello World");
        // 버튼에 핸들러 지정
        btn.setOnAction((ActionEvent event) -> {
            // printing Hello World! to the console
            System.out.println("Hello World!");
        });

        StackPane root = new StackPane();
        
        root.getChildren().add(btn);
        
        Scene scene = new Scene(root, 300, 250);
        
        primaryStage.setTitle("Hello World!");
        primaryStage.setScene(scene);
        
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

# VO

VO란 도메인에서 한 개 또는 그 이상의 속성들을 묶어서 특정 값을 나타내는 객체를 의미

### DO

Domain Object의 약자로 Domain에서 사용하는 데이터를 객체화 시킨 것

### VO

Value Object의 약자로 각 table의 하나의 row를 담을 수 있는 객체

table의 일부 데이터만 담아도 상관 없음

### Entity

VO 중 PK를 가지고 있는 객체

### DTO

Data Transfer Object의 약자

객체의 구성은 VO와 같음 목적이 데이터를 전달하기 위함이면 DTO라고 함

# MVC Pattern

## Layered Architecture

### 4-tier Architecture

- Presentation Layer
    - 입출력 처리
    - 대표적으로 View와 Controller가 있음
- Business Layer
    - 로직 처리
    - Service, Domain Model
- Persistence Layer
    - DB 접근
    - Repository, DAO
- Database Layer
    - 실제 데이터베이스
    - Oracle, MySQL

### Layers of isolation

각 계층은 수직적이며 독립적이다. 따라서 각각 유지보수가 가능하다.

## MVC Pattern

Model, View, Controller 3가지로 나누어서 관리

도메인 영역과 UI 영역이 분리되어 각각 독립적으로 유지보수가 가능
